Revision History
================
## 2024.1 Release

* 2 x 25G
* 2 x 10G
* Added Synchronous Ethernet (SyncE) support
* Added pcm4l support 
* Unicast PTP packet support
* Conformance test report
* Updated ptp4l package to 4.3 version
* Reduced the MCDMA channels from 16 to 1 to minimize resource utilization
* Resource utilization graph is updated.


## 2023.2 Release

* Plain Upgrade

## 2023.1 Release

* Recovered clock logic is added to the design to support syncE.
* Enabled XXV MAC User Register to reset GT QPLL.
* In the axi_dma_hier, axis_rxd_fifo and axis_txd_fifo depths are reduced to 8K to minimize Resource Utilization.
* Resource utilization graph is updated.

## 2022.2 Release

* First Release
